# Raft

Raft creates **persistent Linux boxes on your own Ubuntu hosts**. Run commands,
Docker builds and development services; copy files; save snapshots; or open a
private desktop. A box is an unprivileged Incus container that shares its host's
kernel, not a virtual machine.

## Start here

1. [Check requirements](./requirements.mdx): a Linux controller and a dedicated Ubuntu host.
2. [Set up a host](./operations.mdx): install the CLI and run guided onboarding.
3. [Create your first box](./first-box.mdx): run a command, stop it and resume it.

Already have a configured host? Run these commands on your **controller**
(the machine where you installed `raft`). Replace `lab` with your location:

```sh
box=$(raft new --location lab --ttl 600 --persistent)
raft exec "$box" -- node --version
raft ssh "$box"
```

Exit the guest shell, then run `raft stop "$box"` on the controller. Files remain;
processes stop. Host retention policies can later delete stopped boxes.
