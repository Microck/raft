# Raft

Run commands, Docker builds and development services in Linux boxes on your own hosts. You can copy files, save snapshots, fork a prepared box, or open a private desktop.

Your controller runs the CLI and connects over host SSH. Each box is an unprivileged Incus container sharing its host's kernel, not a VM. Use dedicated hosts and trusted workloads; Raft is a single-operator tool, not a multi-tenant service.
