# Raft

Raft is an independent, self-hosted open-source alternative to [boat.dev](https://boat.dev).
It provides persistent Linux workspaces on ARM64 and AMD64 hardware,
supporting command execution, Docker, file transfer, snapshots, forks, and desktop access.
Raft is not affiliated with Boat.

## Getting started

Read [System requirements](./requirements.mdx), follow [Installation and host setup](./operations.mdx), and create your [First working box](./first-box.mdx).

```sh title="CONTROLLER: Create and use a workspace"
box=$(raft new --location lab --ttl 600)
raft exec "$box" -- node --version
raft ssh "$box"
raft stop "$box"
```

Stopping a workspace preserves files and packages on disk. Resuming resets its running lifetime.
