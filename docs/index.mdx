# Raft

Raft is an independent, self-hosted open-source alternative to [boat.dev](https://boat.dev).
It provides persistent Linux workspaces on your own ARM64 or AMD64 hardware,
with command execution, Docker, file transfer, snapshots, forks, and private desktop access.
Raft is not affiliated with Boat.

## Getting started

Review [System requirements](./requirements.mdx), proceed through [Installation and host setup](./operations.mdx), and launch your [First working box](./first-box.mdx).

```sh title="CONTROLLER: Create and use a workspace"
box=$(raft new --location lab --ttl 600)
raft exec "$box" -- node --version
raft ssh "$box"
raft stop "$box"
```

Stopping a workspace retains files and installed packages on disk. Resuming it renews its running lifetime.
