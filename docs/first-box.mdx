# First working box

Launch and manage a workspace after provisioning your host and pinning the image fingerprint (see [Installation and setup](./operations.mdx)).

## Step 1: Launch a workspace

Create a workspace with `raft new`:

```sh title="CONTROLLER: Create a new workspace"
box=$(raft new --location lab --ttl 600 --persistent)
echo "Created workspace: $box"
```

The command returns a location-qualified handle formatted as `<location>:<instance-name>` (for example `lab:rf-a1b2c3d4e5f60718`).

Without a configured location default, omitting `--location` targets the first location in `~/.config/raft/incus.json`. The `--ttl` flag sets the lifetime in seconds (default: 600).

## Step 2: Verify command execution and Docker daemon

Execute commands inside the container with `raft exec`:

```sh title="CONTROLLER: Verify runtime tools and Docker daemon"
raft exec "$box" -- node --version
raft exec "$box" -- docker version
raft exec "$box" -- docker info
```

<Callout type="info" title="Daemon readiness check">
`docker version` and `docker info` verify guest `dockerd` readiness. Running `docker --version` inspects only the client binary without checking the daemon.
</Callout>

Arguments after `--` pass directly to `execve`. For pipes, redirects, or environment variables, wrap the command in `bash -lc '...'`.

## Step 3: Open an interactive terminal

Open a root terminal session inside the container:

```sh title="CONTROLLER: Open interactive root shell"
raft ssh "$box"
```

Type `exit` or press `Ctrl+D` to disconnect.

<Callout type="info" title="User namespace security">
Commands run as root in `/workspace` inside an unprivileged Linux user namespace. Container root maps to an unprivileged high UID on the host, sharing the host kernel.
</Callout>

## Step 4: Stop and resume

Manage the workspace lifecycle:

```sh title="CONTROLLER: Stop and resume workspace"
# Stop running processes while preserving files and snapshots
raft stop "$box"

# Resume the stopped workspace with a renewed lifetime
raft resume "$box" --ttl 600

```

- **`raft stop`**: Stops running processes and frees active allocations while retaining files and snapshots.
- **`raft resume`**: Starts a stopped container with a new expiration deadline (`now + TTL`). Does not restore process memory.
- **`raft destroy`**: Permanently deletes the container, filesystem, and snapshots from the host storage pool.

## Clean up when finished

<Callout type="warn" title="Permanent deletion">
Destroy only the tutorial box after copying out anything you need. This removes
its files and snapshots; it is not the same as stopping it.
</Callout>

```sh
raft destroy "$box"
```
