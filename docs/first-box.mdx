# Run your first command

You can stop a persistent box and resume with its files intact. First [set up a host](./operations.mdx); these examples use location `lab`. Run commands on your controller unless you are inside the interactive guest shell.

## Create a persistent box

```sh
raft config --location lab
box=$(raft new --location lab --ttl 600 --persistent --purpose "Explore Raft" --owner "Local operator" --next "Destroy after exploring")
printf '%s\n' "$box"
```

Keep the returned handle, such as `lab:rf-a1b2c3d4e5f60718`. `--persistent` overrides a disposable controller default. Check the policy report first: stopped persistent boxes can still be deleted by host retention.

The box has a 600-second lifetime. Omitted CPU, RAM and disk settings come from controller defaults, otherwise 1 CPU, 2 GiB and shared storage. Creation returns before every guest service is ready.

## Run a command or open a shell

```sh
raft exec "$box" -- node --version
raft exec "$box" -- docker info
raft ssh "$box"
```

Commands run as guest root in `/workspace`. `exec` passes literal arguments; use `bash -lc '...'` for pipes, redirects or variable expansion. `docker info` checks the daemon, unlike `docker --version`.

Type `exit` to leave the guest shell. If a command fails during startup, check readiness before retrying your workload. See [readiness and failure handling](./guides/scripting-ci.mdx).

## Keep your files across a stop

Stopping ends every guest process without saving process memory. It deletes a disposable box, so use the persistent box created above:

```sh
raft stop "$box"
raft resume "$box" --ttl 600
raft exec "$box" -- ls /workspace
```

Activity does not renew the deadline. Use `raft extend "$box" --ttl 1800` while the box is running to reset it to 1,800 seconds from the host's clock.

## Delete the tutorial box

Copy out anything you need first. The following command permanently deletes this box and all its snapshots:

```sh
raft destroy "$box"
```
