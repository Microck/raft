# System requirements

Raft coordinates unprivileged Linux system containers across two environments: dedicated workspace hosts running Incus, and a controller machine running the Raft CLI.

## Workspace host requirements

Each workspace host must be a dedicated physical machine or virtual instance:

| Component | Requirement | Notes |
| :--- | :--- | :--- |
| **Architecture** | ARM64 or AMD64 | Workspaces run native binaries matching the host CPU architecture. |
| **Operating system** | Ubuntu 22.04 LTS or 24.04 LTS | The deployer installs Incus 6.0 LTS and nftables bridge isolation rules. |
| **CPU** | At least 2 CPU cores | Capacity calculations reserve 1 CPU core for the host OS and services (an advisory estimate, not an enforced host reservation). |
| **RAM** | At least 8 GiB | Sizing calculations reserve the larger of 2 GiB or 10% of host RAM (an advisory estimate, not an enforced host reservation). |
| **Free disk** | At least 80 GiB on host disk | The deployer provisions a 60 GiB dedicated Btrfs pool (`raft-data`). |

Resource reserves for host CPU and RAM are advisory estimates used by `raft limits` capacity calculations, not enforced host reservations or cgroup locks.

<Callout type="warn" title="Dedicated host requirement">
Do not deploy Raft on a host with existing production Incus storage pools or shared virtualization workloads. The deployment configures dedicated nftables rules, storage pools, and system services for Raft.
</Callout>

### Host access and permissions

- **SSH access**: You must have SSH access to the host as a user with passwordless `sudo` privileges (`sudo -n true`).
- **Single-operator security model**: Sudo privileges on the host grant full root access. Deploy only on hardware and networks you trust.
- **Network connectivity**: Hosts require outbound internet access to download Debian packages, Incus release packages, and container images. Inbound SSH (default port 22 or configured port) is required from your controller. No public Incus listener or cloud management account is needed.

## Controller machine requirements

The controller is your local workstation, developer machine, or continuous integration runner:

| Component | Requirement | Notes |
| :--- | :--- | :--- |
| **Operating system** | Linux | Controller CLI commands invoke standard Linux utilities. |
| **Python** | Python 3.11 or newer | Required to run the `raft` CLI tool. |
| **Toolchain** | `git`, `uv`, OpenSSH client (`ssh`), `scp` | `uv` manages the Python environment; OpenSSH provides the transport. |
| **Network** | Network route to host SSH targets | Batch SSH commands must connect without interactive password prompts. |
