# Lifetime and persistent services

A box's lifetime controls when the host stops or deletes it. Activity, an open
terminal, and detached jobs do not extend that deadline automatically.

## Choose a lifetime and retention policy

```sh title="CONTROLLER: Create a persistent box"
box=$(raft new --location lab --ttl 3600)
```

TTL is in seconds: 60 to 2,592,000 (30 days), with a creation default of 600.
The host sets the deadline after launch completes, using its own clock.
Raft has no option to disable automatic expiry.

| Operation | Persistent box (default) | Disposable box |
| --- | --- | --- |
| `stop` or TTL expiry | Stops processes; keeps disk and snapshots | Deletes the box and snapshots |
| `resume --ttl SECONDS` | Starts the saved box with a new deadline | Only possible while the box still exists |
| `destroy` | Deletes the box and snapshots | Deletes the box and snapshots |

Use `raft new --disposable` for temporary work. A fork is persistent unless
`--disposable` is explicitly supplied; recovered boxes are persistent.
Back up work before stopping a disposable box.

Persistent stopped boxes still occupy a saved slot and storage. Each host allows
four saved boxes. `raft prune --older-than 7` previews old stopped boxes;
`--yes` applies deletion. There is no automatic persistent-box retention cleanup.

## Read and reset the deadline

Select a running handle from `raft list`. These examples use controller `jq`:

```sh title="CONTROLLER: Inspect and extend a running box"
raft list
box="lab:rf-a1b2c3d4e5f60718"  # Replace with your actual handle
raft info "$box" | jq '{status, expires: .config["user.raft.expires"]}'
raft extend "$box" --ttl 7200
raft info "$box" | jq '{status, expires: .config["user.raft.expires"]}'
```

`user.raft.expires` is a Unix timestamp encoded as a string, not a remaining
duration. `raft list` exposes it as `stopAt`; it may be empty on stopped boxes.
`extend` sets `now + TTL`, rather than adding time to the old deadline.
It requires a running box. Start a stopped box with `raft resume "$box" --ttl 7200`.

The host timer checks every 15 seconds. Graceful shutdown, a host outage, or a
long transaction holding the lifecycle lock can delay expiry. `raft gc --location lab`
runs an immediate deadline check. A deadline is not a guarantee that a job will
finish before shutdown; extend before starting work that needs more time.

## Restart a service after resume

One-off detached commands do not survive a stop. To start an application again
after resume or fork, save a systemd unit on disk and enable it. This starts a new
process; it does not recover process memory or an interrupted request.

The following example serves `/workspace` as the guest `developer` user. Use a
persistent running box and ensure files the application needs are readable by
that user. For an actual application, replace `ExecStart` and the working directory.

```sh title="CONTROLLER: Install and enable an example service"
raft exec "$box" -- bash -lc 'cat > /etc/systemd/system/workspace-web.service <<"UNIT"
[Unit]
Description=Workspace HTTP example
After=network.target

[Service]
User=developer
WorkingDirectory=/workspace
ExecStart=/usr/bin/python3 -m http.server 8080 --bind 0.0.0.0
Restart=on-failure
RestartSec=2

[Install]
WantedBy=multi-user.target
UNIT
systemctl daemon-reload
systemctl enable --now workspace-web.service'
raft exec "$box" -- systemctl status workspace-web.service --no-pager
raft exec "$box" -- journalctl -u workspace-web.service -n 30 --no-pager
```

Open `raft forward "$box" --remote 8080 --local 8080` and visit
`http://127.0.0.1:8080`. The tunnel runs in the foreground; close it with `Ctrl+C`.

```sh title="CONTROLLER: Check service startup after resume"
raft stop "$box"
raft resume "$box" --ttl 3600
raft exec "$box" -- systemctl is-active workspace-web.service
```

Reopen the tunnel after resume. A fork or snapshot template copies the enabled
unit too, so its new box starts its own service. Application secrets on disk are
also copied; see [Project setup and templates](./project-setup.mdx).

To disable the example, run:

```sh
raft exec "$box" -- systemctl disable --now workspace-web.service
```

See [Background jobs](./background-jobs.mdx) for one-off tasks and
[Desktop and private services](./desktop-services.mdx) for tunnel behavior.
