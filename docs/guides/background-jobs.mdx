# Background jobs

Raft runs detached commands under guest systemd and captures their results with a transient host supervisor.

## Target workspace handle

Launching a job requires a running workspace. Select one from `raft list` (see [First working box](../first-box.mdx)):

```sh title="CONTROLLER: Select running workspace"
raft list
box="lab:rf-a1b2c3d4e5f60718"  # Replace with your actual workspace handle
```

## Launching detached commands

Start a background command by passing `--detach` to `raft exec`, delimiting the payload with `--`:

```sh title="CONTROLLER: Start a detached background job"
job=$(raft exec "$box" --detach -- bash -lc '
echo "Task started at $(date)"
sleep 60
echo "Task finished at $(date)"
')
echo "Started background job: $job"
```

The command returns a 32-hex systemd unit name prefixed with `rfcmd-` (such as `rfcmd-a1b2c3d4e5f60718293a4b5c6d7e8f90`).

## Checking job status

`raft status "$box" "$job"` returns a retained JSON record:

```json
{"job":"rfcmd-...","box":"lab:rf-...","state":"completed","exitCode":23,"startedAt":1793280000,"finishedAt":1793280010,"droppedBytes":0}
```

States are `starting`, `running`, `completed`, `cancelled`, `interrupted` and
`failed`. `completed` means the command finished, not that it succeeded; inspect
`exitCode`. An interrupted job has no confirmed payload exit code. A transport interruption can leave the guest command running;
inspect or cancel it before rerunning the payload. Timestamps
are host Unix seconds. A successful status query itself returns zero.

## Viewing retained output

```sh
raft logs "$box" "$job"
```

A host supervisor retains the first 1 MiB of combined stdout and stderr. Further
output is drained and counted in `droppedBytes` when the job ends. Logs and final
status remain readable after the workspace stops or is deleted; keep its exact
original handle. They are not copied by workspace snapshots or forks.

Results live in the root-private host directory `/var/lib/raft-jobs`. They expire
seven days after completion. Job commands prune expired records on access, so an
idle host may retain expired files until the next access. The store holds at most
512 records and refuses new jobs when full instead of evicting unexpired results.
Unreadable records remain on the host for inspection and count toward the limit.
They do not block other jobs. A query for a damaged record reports its host path;
inspect that directory and its retained output before deciding how to recover it.
Output can contain secrets; this is host-local retention, not an off-host backup.

## Cancelling jobs

```sh
raft cancel "$box" "$job"
```

Cancellation stops the guest systemd control group. Retained output remains
available. If a job is still starting and its guest unit is not yet registered,
cancellation reports an error; inspect its state before retrying. Unknown job
IDs and IDs belonging to another workspace are rejected. Cancellation waits up to
120 seconds. If it times out, the cancellation request remains recorded; inspect
the job and retry cancellation.

Host reboot or guest shutdown interrupts active jobs. The next inspection marks
an absent supervisor as interrupted rather than assuming success. Completed
results survive host reboot. This development implementation has no fallback to
old guest-only journals; inspect old jobs with their controller version before
upgrading.

## Extending workspace lifetime

<Callout type="warn" title="No process checkpointing">
Stopping a workspace with `raft stop` or allowing its TTL to expire terminates all running background jobs. Raft does not checkpoint running process memory.
</Callout>

Extend the workspace lifetime before it expires:

```sh title="CONTROLLER: Reset workspace expiration"
raft extend "$box" --ttl 1800
```

`raft extend` resets the container expiration deadline to `now + TTL` seconds using the host clock. It does not add time to the existing deadline.

For deadline inspection and an enabled systemd service that starts again after
resume or fork, see [Lifetime and persistent services](./long-running-services.mdx).
