# Open a desktop or private service

You can reach a running box through a private tunnel bound to `127.0.0.1` on your controller. Set `$box` to your task's handle from `raft list`. You need an available local port and working host SSH.

Guest services must listen on `0.0.0.0` or the guest's managed network address. A service bound only to guest `127.0.0.1` cannot receive forwarded traffic. Raft does not provide public hosting or reverse forwarding.

## Open a web service

Start a server in `/workspace`, then open the tunnel:

```sh
job=$(raft exec "$box" --detach -- python3 -m http.server 8080 --bind 0.0.0.0)
raft forward "$box" --remote 8080 --local 8080
```

In your controller's browser, open `http://127.0.0.1:8080`. The tunnel stays in the foreground. Press Ctrl+C to close it, then stop this example server with `raft cancel "$box" "$job"`.

Closing a tunnel does not stop the service or extend the box's lifetime. After a box resumes, restart one-off servers and reopen the tunnel. Use an [enabled service](./long-running-services.mdx) for automatic startup.

If forwarding fails, check the guest listener and `raft logs "$box" "$job"`. If the local port is occupied, choose another `--local` port. Forwarding waits up to 30 seconds for the managed guest IPv4 address, not for application readiness.

## Open the desktop

```sh
raft desktop "$box" --local 6080
```

Open `http://127.0.0.1:6080/vnc.html` in your controller's browser. Include `/vnc.html`; `/` displays a directory index. The desktop runs as `developer` at 1280×720 on display `:99`. Use the noVNC sidebar for text clipboard exchange.

The command starts `raft-desktop.service` if needed, then opens a foreground tunnel. It does not wait for noVNC HTTP readiness; retry the browser request if startup is still in progress. Press Ctrl+C to close only the tunnel. Reconnect with the same command without closing guest windows.

To stop the desktop itself, run `raft exec "$box" -- systemctl stop raft-desktop`. Stopping or expiring the box also ends the session. If startup fails, inspect `raft exec "$box" -- journalctl -u raft-desktop -n 50 --no-pager`.
