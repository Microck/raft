# Release notes

The setup examples use **0.7.0**, the latest published npm package and GitHub
release checked on 2026-10-31. [GitHub releases](https://github.com/Microck/raft/releases)
are the source for downloadable packages, images and checksums.

- [0.7.1 — unreleased](./0.7.1.md): stdin through `raft exec`, address wait for `forward`, and the Sandbox SDK provider.
- [0.7.0](./0.7.0.md): disposable foreground CI jobs.
- [0.6.0](./0.6.0.md): disposable defaults and stopped-box retention.
- [0.5.0](./0.5.0.md): flexible sizing, own box disks, defaults and self-update.
- [0.4.0](./0.4.0.md): box notes.
- [0.3.0](./0.3.0.md): guided host onboarding.
- [0.2.1](./0.2.1.md): worker compatibility checks.
- [0.2.0](./0.2.0.md): extended workspace lifecycle and transfer commands.

Historical notes describe their own release, not the current command contract.
For upgrades, follow [Upgrades and image changes](../guides/upgrades.mdx).
