# Raft 0.8.0

## Desktop streaming

`raft desktop BOX` now opens [Voxl](https://github.com/tembo/voxl), which streams the desktop as H.264 to your browser. Open the printed viewer URL at `/` instead of `/vnc.html`. Voxl needs a browser with H.264 WebCodecs support and a secure context such as HTTPS or localhost.

You can still select noVNC explicitly:

```sh
raft desktop BOX --backend novnc
```

That command prints a viewer URL ending in `/vnc.html`. Both backends use the same desktop, so switching preserves open windows. They can run together with different `--local` ports. Raft does not switch backends automatically.

The desktop and streamers run as `developer`. Voxl supports file transfer under `/workspace`, with uploads in `/workspace/Downloads`. Desktop audio and microphone are disabled. Access stays behind the private SSH tunnel; do not expose the guest streaming ports publicly.

## Upgrade

Updating the CLI does not install the desktop services into existing boxes. Use the updated native image and create a fresh box. Existing boxes are not migrated, and a missing backend service fails with guidance instead of falling back.

See [upgrades](../guides/upgrades.mdx) for image pinning and [desktop access](../guides/desktop-services.mdx) for backend selection and service controls. Historical noVNC startup timings and image sizes are not measurements of the Voxl image.
