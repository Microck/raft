# Raft 0.2.1

- `raft doctor` now rejects an incompatible host expiry worker and identifies the location that needs deployment. It does not run expiry or change boxes.
- Lifecycle transactions close controller stdin so allocation cannot wait for piped input while holding the host lock.

Install on Linux with Python 3.11.8+ using `npm install -g @microck/raft@0.2.1`, or install the attached Python wheel. Updating the CLI does not update host workers. Deploy the matching checkout to hosts that fail the readiness check.

Exec, SSH, and file-transfer behavior is unchanged. Piped input to `raft exec` is unsupported.

ARM64 and AMD64 development images accompany this release. Verify `SHA256SUMS` before importing an image for your host architecture.
