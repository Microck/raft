# Raft 0.2.0

Install the CLI with `npm install -g @microck/raft` on Linux with Python 3.11.8+, or use the Python wheel/source archive attached to this release. The command remains `raft`.

- Disposable boxes delete themselves on stop or expiry. Persistent boxes keep their files by default.
- `prune --older-than DAYS` previews stopped boxes eligible for deletion. Add `--yes` to apply it.
- Create boxes from named snapshots and delete snapshots directly.
- Upload and download directories, with no-overwrite publication and rejection of unsafe links, special files, incomplete streams and source-replacement races.
- Resize CPU/RAM on resume or fork. Omitted limits are preserved.
- `raft --version` reports the installed release.

Redeploy the host worker from this release before using disposable creation or retention cleanup. npm installation does not configure hosts or install Python; follow the [setup guide](https://raft.micr.dev/docs/operations).

ARM64 and AMD64 development images, manifests, package inventories and startup reports accompany this release. Verify `SHA256SUMS` before importing the archive for your host architecture.

Both architectures pass native lifecycle, desktop, development-tool, capacity, directory-transfer and full-image recovery checks. Fresh provisioning, image import, firewall ordering and reboot pass on a disposable AMD64 host.

Raft is an independent open-source alternative to boat.dev. Containers share the host kernel. Physical storage capacity, ARM64 host reboot and cross-architecture recovery are outside the verified scope.
