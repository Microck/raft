# Raft 0.7.1

**Unreleased.** These changes are on the development branch.

- **`raft exec` forwards piped stdin.** `printf data | raft exec BOX -- cat` now delivers the
  data. Before, the box lookup that runs ahead of the command read stdin first, and the
  command got none. Raft's own lookups and lifecycle calls now read from `/dev/null`;
  only `exec`, `ssh` and the `run` payload receive the caller's stdin.
- **`forward` and `desktop` wait for a new box's address.** Run right after `raft new`, they
  failed with "Running box has no eth0 IPv4 address yet" until the box got its DHCP lease.
  They now wait up to 30 seconds for it.
- **Sandbox SDK provider.** The new [`@microck/sandbox-sdk-raft`](https://github.com/Microck/raft/tree/main/sandbox-sdk)
  package runs [Sandbox SDK](https://sandbox-sdk.app) sandboxes on Raft boxes through this CLI.
  It needs 0.7.1 for stdin forwarding.

After release, hosts need no redeploy for this version: the expiry worker protocol is
unchanged.
