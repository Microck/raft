Raft

An independent open-source alternative to boat.dev for persistent Linux workspaces on your own hosts.

The controller sends commands through authenticated host SSH. Incus manages unprivileged system containers. A host timer stops expired workspaces and retains their files.

Containers share the host kernel. Desktop access uses a private SSH tunnel to noVNC. Public hosting and managed coding-agent conversations are not implemented.
